# CompuMaster.Scopevisio.OpenApi 2026.10.13.0

This release expands the OpenScope client against the current manufacturer contract while preserving existing public signatures and defaults. Changes cover the complete diff since CompuMaster.Scopevisio.OpenApi 2026.10.07.0.

- Completes native cancellation exposure for all 137 current GET routes and adds many explicit search and mutation workflows. Cancellation reaches active HTTP I/O; a cancelled write does not establish its server outcome and is not automatically replayed.
- Adds complete contact/project/task, sales/product, accounting, cashbook, personnel, time/team and reporting reads/searches, with current fields, paging, count, date, number-range and product options selected explicitly by the caller.
- Adds copied extensible request models and complete results for financial imports, posting/cancellation/correction, account/VAT/reminder/planning/material workflows, cashbook entries, deletions and sales/recurring-invoice conversions. Legacy methods remain available. Required internal IDs, document numbers, epoch timestamps and date-string workflows remain distinct.
- Preserves complete unspecified JSON, raw responses, status and response/content headers; adds binary invoice/journal/thumbnail/export reads, decoded invoice Teamwork links and the documented advanced Teamwork GET bridge. Parsed JSON fractions remain subject to .NET decimal precision/range; raw content is retained.
- Fixes legacy raw JSON search bodies and response-header preservation, and preserves original response failures as inner exceptions. Keeps authorization, account selection and historical generated defaults separate from new explicit workflows.
- Adds pinned public-contract provenance, conservative coverage inventory, bounded generation/import checks and published compiled/default compatibility with unchanged consumers. The 13 October public contract matches the 12 October bytes; only six timestamp examples differ from the immutable 11 October snapshot.
- Serializes this repository's live test workflows and validates release-tag/package-version agreement before publication.

Compatibility and verification cover three SDK targets (netstandard2.0, net6.0 and net48), 13,923 isolated regression cases per Windows runtime, conservative inventory/generation checks, compiled public API/default metadata, unchanged consumers and seeded compatibility-checker regressions. The package retains its existing dependency versions.

This is a substantial additive release, with remaining work: 63 non-GET operations still lack native-cancellation forms, and all 323 full contract/live support decisions remain deferred. Existing server tests and isolated wire tests do not establish every new financial/profile/permission or real-account outcome. Advanced Teamwork integration retains the known [selected-comment route limitation](https://github.com/CompuMasterGmbH/CompuMaster.Scopevisio.Teamwork/issues/9) and [upstream server-error investigation](https://github.com/CompuMasterGmbH/CompuMaster.Scopevisio.Teamwork/issues/10). Full API parity and downstream DMS adoption are not claimed.
