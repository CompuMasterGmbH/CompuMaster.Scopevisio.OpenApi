# CompuMaster.Scopevisio.OpenApi 2026.10.16.0

NuGet package: `CompuMaster.Scopevisio.OpenApi` **2026.10.16** (NuGet normalizes the trailing zero).

Changes since 2026.10.13.0:

- Add explicit numeric organisation selection for credential authorization, with fresh identity validation and no fallback to the default organisation. Existing name/default selection remains compatible.
- Complete additive current write requests and result methods for contacts, contact properties, comments, products/groups, projects/teams, tasks/subtasks, time entries and sales projects. Preserve caller selections, sparse values, future JSON and copied nested data.
- Complete current accounting, bank-connection, payment-term, dimension, posting and DATEV contracts; incoming/outgoing invoice imports, recurrence updates, file attachments, mail assignment and EML imports now have additive complete-result methods with native cancellation.
- Add complete current user-batch and organisation-creation requests and explicit low-level organisation token-change results without implicit privileges, account selection or financial actions.
- Complete current Teamwork file requests and bridge mutation transport. Fix bridge reads to preserve literal encoded-looking resource segments by escaping each original segment independently.
- Preserve optional token customer/public-number metadata, account customer origin, and account user licence/profile metadata.
- Fix the historical test harness's first account read after cold-cache authorization. Guard current native result source mappings with durable offline regressions.
- Retain existing synchronous/generated APIs, default behavior and package dependencies. All 323 current operations now have public native asynchronous HTTP-info source mappings; source coverage does not establish complete server/business support.
- Run full isolated Windows/net8 verification and limit all secondary platform/framework samples to 20 unit tests combined (eight Windows/net48, six Linux/net8 and six macOS/net8). Manual CI supports credential-free release verification.

The maintainer accepted the implemented behavior on the completed isolated and bounded server tests. Teamwork live acceptance remains excluded. The statistics-unit HTTP 403 investigation ([#239](https://github.com/CompuMasterGmbH/CompuMaster.Scopevisio.OpenApi/issues/239)) and historical extended contact creation without acknowledgement ([#240](https://github.com/CompuMasterGmbH/CompuMaster.Scopevisio.OpenApi/issues/240)) remain open. Additional fixtures and wider contract coverage are tracked in [#241](https://github.com/CompuMasterGmbH/CompuMaster.Scopevisio.OpenApi/issues/241).

Targets remain `netstandard2.0`, `net6.0` and `net48`. This release does not change downstream Teamwork or DMS package pins.
