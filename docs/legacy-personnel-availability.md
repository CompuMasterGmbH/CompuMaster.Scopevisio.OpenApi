# Explicit deprecated personnel availability range

Parent [#17](https://github.com/CompuMasterGmbH/CompuMaster.Scopevisio.OpenApi/issues/17), focused [#152](https://github.com/CompuMasterGmbH/CompuMaster.Scopevisio.OpenApi/issues/152), consumer [DMS #90](https://github.com/CompuMasterGmbH/CompuMaster.Dms/issues/90).

The pinned manufacturer contract explicitly deprecates POST `/humanresourcesAvailability`. `SearchHumanResourceAvailabilityLegacy` adds six explicitly obsolete JSON/native cancellation forms for callers maintaining this range workflow. The existing modern `GetHumanResourceAvailability` uses POST `/humanresourcesavailability/v2` and caller-selected yyyy-MM values. Select that workflow for new applications; the SDK does not convert or redirect legacy dates to it.

`HumanResourceAvailabilityLegacyRequest` requires explicit `validFrom` and `validTill` Int64 Unix epoch milliseconds. The server considers year/month. Example first-/last-day-of-year extensions do not insert client defaults. Full signed Int64 values, zero and independently selected range values are forwarded without date conversion, minimum or ordering constraints absent from the schema. The optional nullable `searchSpecification` is a copied extensible object. Typed null omits it; inherited indexers allow explicit JSON null. Empty objects, future fields and original filters are retained. The manufacturer excludes month, monthRevenue and id from search; the SDK does not rewrite caller filters. Human-Ressourcen Verwaltung (Anzeigen) is server-authoritative.

Every call deeply copies, validates and serializes the whole JSON request before HTTP admission. Required integer kinds/widths, optional search object/null and finite JSON numbers are checked. It posts recommended application/json to the exact camel-case route, with no query/default/paging/retry. HTTP 200 has no declared response shape. Shared JSON handling retains arbitrary objects, arrays, scalars, JSON null, empty-body null, status, headers and exact RawJsonContent; parsed fractional values have bounded .NET decimal precision. ExceptionFactory is invoked under the original new operation name before parsing; original hook/error behavior remains authoritative. Native cancellation reaches active I/O and pre-cancellation prevents HTTP.

Historical `GetHumanResourcesYear` methods, original form/body behavior and JObject results remain unchanged. The existing modern v2 methods/models, personnel allocations, account selection, token refresh and generated sources remain unchanged.

The isolated fixture first reproduced 122 missing-model/form failures with one historical regression passing. Its final 150 cases cover all six forms, full-width/invariant independent range values, missing/invalid/overflow inputs, omitted/null/empty/search future fields and defensive snapshots, unknown JSON/raw/status/headers, malformed/overflow responses, original errors/hooks and pre-/active cancellation. No real account or server is accessed. Coordinated legacy date/month/profile/search acceptance, required combined matrix, publication and DMS consumption remain separate prerequisites; this implementation does not establish v2 equivalence or full API support.
